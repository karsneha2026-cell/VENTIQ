# 🎟️ VENTIQ – Event Discovery & Ticket Booking Platform

**Discover Events. Book Experiences.**

VENTIQ is a web-based event discovery and online ticket booking platform designed to make finding and booking events simple and convenient. Users can explore upcoming events, discover concerts and festivals, book tickets online, and manage their accounts. The platform also includes an admin dashboard to manage events, monitor bookings, track registered users, and view revenue statistics.

## 🌐 Live Website

**Explore VENTIQ here:** [https://ventiq-1.onrender.com](https://ventiq-1.onrender.com)

## ✨ Key Features

- 🏠 **Home Page:** Explore featured and upcoming events.
- 🔍 **Event Discovery:** Browse different events, concerts, festivals, and more.
- 🎫 **Online Ticket Booking:** Book tickets through a simple booking process.
- 🔐 **User Authentication:** Register and log in to your account.
- 📊 **Admin Dashboard:** Manage events and monitor bookings, users, and revenue.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python (Flask)
- SQLite

## 🎯 Project Goal

The goal of VENTIQ is to provide a convenient platform where users can discover events and book experiences online, while simplifying event management through an admin dashboard.
